=== HƯỚNG DẪN SỬ DỤNG ===

Phần này hướng dẫn cách biên dịch và chạy chương trình. 
Vui lòng đảm bảo bạn đã cài đặt đầy đủ các công cụ và thư viện theo file HuongDanCaiDat.txt.

BƯỚC 1: KHỞI ĐỘNG HẠ TẦNG (DATABASE, NGINX, PROMETHEUS)
- Mở terminal tại thư mục gốc của dự án.
- Chạy lệnh:
  docker compose up -d
- Lưu ý: Lệnh này sẽ start PostgreSQL Database (db), Nginx và Prometheus dưới nền.

BƯỚC 2: BIÊN DỊCH VÀ CHẠY FRONTEND
- Mở một cửa sổ terminal mới.
- Di chuyển vào thư mục frontend: 
  cd frontend
- Chạy ứng dụng ở chế độ phát triển (development):
  npm run dev
- (Nếu muốn biên dịch ra file tĩnh để deploy, sử dụng lệnh: npm run build)

BƯỚC 3: BIÊN DỊCH VÀ CHẠY BACKEND
- Mở một cửa sổ terminal mới.
- Di chuyển vào thư mục backend:
  cd backend
- Chạy ứng dụng (Spring Boot):
  + Trên Windows: .\mvnw.cmd spring-boot:run
  + Trên Linux/macOS: ./mvnw spring-boot:run
- (Nếu muốn biên dịch ra file JAR, sử dụng lệnh: ./mvnw clean package -DskipTests)

BƯỚC 4: BIÊN DỊCH VÀ CHẠY MOBILE (Tùy chọn nếu cần test app)
- Mở một cửa sổ terminal mới.
- Di chuyển vào thư mục mobile_flutter:
  cd mobile_flutter
- Chạy ứng dụng trên máy ảo hoặc thiết bị thật đã kết nối:
  flutter run
