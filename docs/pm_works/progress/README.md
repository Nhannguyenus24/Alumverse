# Báo cáo tiến độ dự án

Thư mục chứa các báo cáo tiến độ theo tuần/kỳ.

## Quy ước đặt tên file

- `tuan-01.md`, `tuan-02.md`, ... (theo tuần)
- hoặc `2025-01-week1.md` (năm-tháng-tuần)
- hoặc `progress-YYYY-MM-DD.md` (theo ngày báo cáo)

## Cách sử dụng

1. Copy `TEMPLATE_BAO_CAO_TIEN_DO.md` thành file mới
2. Đổi tên theo quy ước trên
3. Điền nội dung theo từng mục
