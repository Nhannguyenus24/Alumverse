## Mô tả tóm tắt

Hệ thống Alumnverse tập trung vào việc tái cấu trúc và nâng cấp hệ thống sinh viên - cựu sinh viên cho HCMUS:

- **Thay đổi hướng tiếp cận:** Từ mô hình mạng xã hội (engagement thấp) sang **giá trị đóng góp cốt lõi** — mentorship, cơ hội nghề nghiệp, chuyên môn, đóng góp, vinh danh.
- **Multi-tenant:** Cung cấp bộ công cụ chung để các khoa khác tạo trang alumni riêng (subdomain).
- **Tính năng ưu tiên:** Mentorship, Forum sự nghiệp, Sự kiện, Chat, Nội dung (tin tức, việc làm, thành tựu).
- **Mục tiêu:** Hệ thống chạy thực tế (production), phục vụ người dùng thật — không chỉ đồ án demo.
- **Hình thức:** Web responsive (máy tính + trình duyệt trên điện thoại).

## Công nghệ sử dụng

- **Frontend:** React 19, Vite 7, Material UI 7, Zustand, React Router, Axios, React Hook Form + Zod
- **Backend:** Spring Boot 3.5, WebFlux (reactive), R2DBC (PostgreSQL), Spring Security, JWT
- **Database:** PostgreSQL
- **DevOps / Deploy:** Docker Compose
