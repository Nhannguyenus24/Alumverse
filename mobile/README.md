# Mobile App Quick Start

- Install dependencies: `npm install`.
- Set `EXPO_PUBLIC_API_BASE_URL` and `EXPO_PUBLIC_WEB_BASE_URL` in `.env`. Use your machine IP address; `localhost` will not work on a phone.
- Start the backend and frontend servers.
- Run the mobile app: `npx expo start -c`.
- Install Expo Go on your phone.
- Connect your phone and computer to the same Wi-Fi network.
- Scan the QR code with Expo Go and enter your organization slug.
